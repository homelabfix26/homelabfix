KALKULATORY HOME LAB&FIX — PACZKA STRONY

To jest statyczna strona HTML/CSS/JS inspirowana funkcjonalnością hubu PracticalCalcHub:
- strona główna z hero,
- kategorie kalkulatorów,
- wyszukiwarka,
- lista narzędzi,
- działające formularze kalkulatorów,
- wynik + opis obliczenia,
- sekcja popularnych kalkulatorów,
- responsywność pod telefon.

Pliki:
1. index.html — struktura strony
2. style.css — wygląd strony
3. app.js — dane kalkulatorów i logika obliczeń

Jak uruchomić lokalnie:
1. Rozpakuj ZIP.
2. Otwórz index.html w przeglądarce.

Jak wrzucić na GitHub Pages z telefonu:
1. Wejdź na GitHub.
2. Otwórz repozytorium: Kalkulatory-Home-Lab-Fix-
3. Kliknij Add file → Upload files.
4. Wgraj 3 pliki: index.html, style.css, app.js.
5. Kliknij Commit changes.
6. Wejdź w Settings → Pages.
7. Ustaw:
   Source: Deploy from a branch
   Branch: main
   Folder: /root
8. Kliknij Save.
9. Publiczny link powinien wyglądać tak:
   https://homelabfix26.github.io/Kalkulatory-Home-Lab-Fix-/

Jak wrzucić na Netlify:
1. Wejdź na https://app.netlify.com/drop
2. Rozpakuj ZIP.
3. Wgraj cały folder z plikami.
4. Netlify nada publiczny link automatycznie.

Uwaga:
Projekt nie kopiuje cudzej strony 1:1. Odtwarza podobny typ funkcjonalności i strukturę hubu kalkulatorów, ale z własnym wyglądem, tekstami i marką Home Lab&Fix.
